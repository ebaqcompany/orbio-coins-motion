# Fonts

The headline uses **ABC Arizona Flare Regular** by Dinamo (https://abcdinamo.com/typefaces/arizona). It is a paid font, so it isn't included here.

After licensing it, put the file in this folder with exactly this name:

- `ArizonaFlare-Regular.woff2` (preferred), or
- `ArizonaFlare-Regular.otf`

Without it the headline falls back to a default serif, so the layout still works but won't look on-brand.

Geist Mono (the button label) loads from Google Fonts automatically.
